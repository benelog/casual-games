# Casual Games

브라우저에서 바로 즐기는 간단한 게임 모음. 게임마다 디렉토리를 하나씩 쓴다.
https://casual-games.benelog.net 에 배포되어 있고, PWA 라 홈 화면에 설치할 수 있다.

| 디렉토리 | 게임 |

## 실행

빌드 과정은 없다. 다만 `index.html` 을 파일로 직접 열면(`file://`) 동작하지 않는다. 브라우저가
`file://` 에서는 ES 모듈 스크립트와 텍스처·모델 로딩을 보안상 막기 때문이다. 정적 서버로 연다.

```sh
npm start        # python3 -m http.server 8000
```

http://localhost:8000 에서 게임을 고른다.

```sh
npm test         # node --test
```

## 새 게임 추가

1. 최상위에 게임 디렉토리를 만들고 `index.html` 을 둔다. `<head>` 에는 다른 게임처럼 manifest·아이콘·
   `../shared/pwa.js` 줄을 넣는다.
2. 루트 `index.html` 의 `games` 배열에 항목(한/영 제목·설명)을 추가한다. `modes` 로 보여 줄 탭을 정한다:
   혼자서(컴퓨터와 1:1 포함)는 `'solo'`, 여러 사람이 할 수 있으면 `'multi'`, 둘 다면 둘 다 적는다.
3. 렌더러는 `shared/gpu.js` 의 `createRenderer(THREE, options)` 로 만든다 (아래 모바일 GPU 참고).

## 공통 모듈 (`shared/`)

- **국제화** `shared/i18n.js`: 한국어/영어. 처음에는 브라우저 언어를 따르고(한국어가 아니면 영어),
  각 화면의 `EN`/`한국어` 버튼으로 바꾸면 localStorage 에 남아 모든 게임에 적용된다.
  게임마다 `js/i18n.js` 에 `{ ko, en }` 사전을 두고 `createT` 로 번역 함수를 만든다. HTML 의 고정 문구는
  `data-i18n` 속성과 `applyI18n(t)` 로 채운다.
- **PWA** `manifest.webmanifest`, `sw.js`, `shared/pwa.js`, `icons/`: 같은 출처 파일은 네트워크를 먼저 쓰고
  안 되면 캐시를, CDN 라이브러리는 캐시를 먼저 쓴다. 한 번 연 게임은 오프라인에서도 열린다.
  껍데기 목록이나 캐시 방식을 바꾸면 `sw.js` 의 `VERSION` 을 올린다.
- **모바일 GPU** `shared/gpu.js`: Pixel 10(PowerVR) 의 Chrome 에서 그림자 맵을 그리다 WebGL 컨텍스트를
  잃고, 그 뒤 Chrome 이 사이트의 WebGL 을 막아 모든 게임이 로딩에서 멈추는 문제가 있었다.
  PowerVR 에서는 그림자를 끄고 픽셀 비율을 1.5 로 낮춘 안전 모드로 그린다(`?safe=1`/`?safe=0` 으로 강제).
  WebGL 을 만들 수 없거나 컨텍스트를 잃으면 로딩 화면에 안내와 다시 불러오기 버튼을 띄운다.
- **카드 크게 보기** `shared/card-zoom.js`: 포커·블랙잭에서 카드 근처를 누르면 테이블의 카드를 줄별로
  크게 펼쳐 보여 준다(모두 뒷면인 줄은 뺀다). 드로우 포커에서 손가락으로 누르면 이 화면에서 바꿀 카드를 고른다.

## 배포

Netlify 가 GitHub `main` 브랜치를 그대로 배포한다(빌드 없음, 설정은 `netlify.toml`). 도메인
`casual-games.benelog.net` 은 Netlify DNS 에서 관리한다. 2026-08-19 이후 무료 플랜에서 만든 프로젝트는
"Powered by Netlify" 배지가 기본으로 켜지므로 Project configuration → General 에서 꺼 둔다.

## 3D 포커

종목은 시작 화면에서 고르거나 `poker/index.html?game=holdem` 처럼 주소로 지정한다.

| 종목 | `game` | 방식 |
| --- | --- | --- |
| 텍사스 홀덤 | `holdem` | 내 카드 2장 + 공용 카드 5장, 노리밋 |
| 오마하 | `omaha` | 내 카드 4장 중 정확히 2장 + 공용 카드 3장, 팟 리밋 |
| 파이브 카드 드로우 | `draw` | 5장을 받고 한 번 교환, 노리밋 |
| 세븐 카드 스터드 | `stud` | 7장 중 4장 공개, 앤티 방식, 공개 패가 높은 쪽이 먼저 베팅 |

- 시작 칩 1,000, 블라인드 10/20 (스터드는 앤티 10). 한쪽 칩이 모두 떨어지면 게임이 끝난다.
- 단축키: `F` 폴드, `C` 체크/콜, `R` 벳/레이즈, `Enter` 다음 핸드.
  드로우에서는 카드를 클릭하거나 `1`~`5` 로 바꿀 카드를 고르고 `Enter` 로 확정한다.
- 종목별 차이는 `poker/js/variants.js` 에 선언되어 있어, 종목을 추가할 때는 여기에 정의를 더한다.

  `scene.js`(Three.js 씬)와 `main.js`(HUD·진행)가 이를 화면에 그린다.
- Three.js 는 CDN 에서 불러오므로 인터넷 연결이 필요하다.
- 3D 모델·텍스처·카드 이미지는 모두 CC0/퍼블릭 도메인 오픈소스 에셋이다. 출처는

## 다트 301

- 시작할 때 컴퓨터와 대전 / 2인 대전(한 기기로 번갈아 던지기)을 고른다.

  남은 점수보다 많이 맞히면 버스트로 그 턴의 점수가 무효가 된다. (더블 아웃 규칙은 없다.)

## 3D 블랙잭

- 시작 칩 1,000, 최소 베팅 10. 칩이 10 아래로 떨어지면 게임이 끝난다.
- 6덱 슈를 쓰고 75% 를 쓰면 다음 라운드 전에 다시 섞는다. 블랙잭은 3:2, 딜러는 소프트 17 을 포함한
  모든 17 에서 스탠드, 푸시는 베팅을 돌려받는다.
- 딜러가 A 를 보이면 인슈어런스(베팅의 절반, 2:1 지급)를 고를 수 있다. 더블은 처음 두 장에서,
  스플릿은 같은 랭크일 때 4핸드까지 가능하다. 스플릿한 A 는 한 장씩만 받는다. 서렌더는 없다.
- 단축키: `1`~`4` 칩, `Backspace` 베팅 지우기, `Enter` 딜, `H` 히트, `S` 스탠드, `D` 더블, `P` 스플릿,
  `Y`/`N` 인슈어런스.
- `blackjack/js/rules.js`(핸드 값·정산), `shoe.js`(슈), `game.js`(진행)는 순수 로직이고
  `scene.js`, `main.js` 가 화면을 담당한다.
- 에셋 출처는 [`blackjack/assets/CREDITS.md`](blackjack/assets/CREDITS.md) 참고.

## 타워 디펜스

- 고정 경로로 기지를 향해 오는 적을 타워로 막는다. 20웨이브를 버티면 승리, 목숨(20)이 0 이 되면 패배.
  5·10·15·20 웨이브에는 보스가 나온다.
- 타워는 궁수탑(빠른 단일 공격), 대포(범위 피해), 빙결탑(둔화) 세 종류. 각각 3레벨까지 업그레이드하고,
  팔면 투자액의 70% 를 돌려받는다.
- `1`~`3` 이나 아래 버튼으로 타워를 고르고 칸을 클릭해 짓는다. 터치는 빈 칸을 탭한 뒤 타워 버튼을 누른다.
  타워를 누르면 사거리와 업그레이드/판매 패널이 나온다.
- 단축키: `U` 업그레이드, `X` 판매, `Space` 웨이브 시작/일시정지, `F` 2배속, `M` 소리, `Esc` 취소.
- 진행 상태는 브라우저 localStorage 에 자동 저장되어 다음에 이어서 할 수 있다. 전투 중의 변화는 저장하지
  않으므로, 전투 중에 새로고침하면 그 웨이브 시작 직전 상태로 돌아간다. 최고 기록도 따로 남는다.
- `defense/js/game.js`(시뮬레이션), `map.js`, `towers.js`, `enemies.js`, `waves.js`(데이터), `save.js`(저장)는
  순수 로직이고 `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.
- 에셋 출처는 [`defense/assets/CREDITS.md`](defense/assets/CREDITS.md) 참고.

## 3D 블록

- 위에서 내려다보는 우물(가로×세로×높이 12)에 입체 조각이 떨어진다. 한 층이 꽉 차면 지워지고 위층이 내려온다.
  새 조각이 나올 자리가 막히면 게임이 끝난다.
- 시작 화면에서 조각 묶음과 우물 크기(3×3, 4×4, 5×5)를 고른다. 최고 기록은 조합마다 따로 남는다.

  | 묶음 | 조각 |
  | --- | --- |
  | 평면 | 도미노, 3칸 2종, 평면 4칸 5종 |
  | 기본 | 평면 + 입체 4칸 3종(세 갈래, 서로 거울상인 두 나사) |
  | 확장 | 기본 + 5칸 8종 |

- 조작은 화면 기준이다. 방향키로 옮기고, `Q`/`A` 앞뒤로 굴리기, `W`/`S` 좌우로 굴리기, `E`/`D` 제자리 돌리기,
  `Space` 바로 떨어뜨리기, `Z` 한 칸 내리기, `P` 일시정지, `M` 소리. 터치는 아래 조작판을 쓴다.
- 우물을 끌면 시점이 돌고(`,`/`.` 은 90°씩, 휠은 확대, 더블클릭은 처음 시점) 이동·회전 방향도 보이는 대로 따라 바뀐다.
- 쌓인 칸은 층마다 색이 다르고, 왼쪽 층 막대에 층별로 얼마나 찼는지 나온다. 금색 윤곽은 떨어질 자리다.
- 여러 층을 한꺼번에 지울수록, 우물을 완전히 비우면 점수를 더 받는다. 지운 칸이 125개 늘 때마다 레벨이 올라 빨라진다.
- `blocks3d/js/pieces.js`(조각·회전), `game.js`(규칙), `controls.js`(화면 기준 조작), `save.js`(기록)는 순수 로직이고
  `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.
- 에셋 출처는 [`blocks3d/assets/CREDITS.md`](blocks3d/assets/CREDITS.md) 참고.

## 양궁

- 리커브 개인전 규정처럼 70m 거리의 122cm 과녁에 쏜다. 한 세트에 두 선수가 3발씩 번갈아 쏘고, 합계가 높으면
  세트 점수 2점(같으면 1점씩). 세트 점수 6점을 먼저 얻으면 이긴다. 5:5 면 한 발 슛오프로, 점수가 같으면 중심에
  가까운 화살이 이긴다. 화살대가 고리 선에 닿으면 높은 점수, 10점 안쪽 고리는 X 로 표시한다.
- 시작할 때 두 방식 중 하나를 고른다.
  - **챔피언십 토너먼트**: 컴퓨터(가상의 선수)와 8강 → 4강 → 결승. 라운드가 오를수록 상대가 정확해지고 바람도 세진다.
    한 번 지면 탈락이고, 세 경기를 모두 이기면 시상식에서 금메달을 받는다 (결승 상대가 은, 4강 상대가 동).
    딴 금메달 수는 localStorage 에 남는다.
  - **2인 대전**: 한 기기에서 번갈아 쏘는 1:1.
- 조준: 마우스는 조준점이 포인터를 따라오고, 누르고 있으면 시위를 당긴다. 막 당기면 크게 흔들리다 1.4초쯤 가라앉고,
  6초가 넘으면 지쳐서 다시 흔들린다. 떼면 쏜다. 터치는 누른 채 끄는 만큼 조준점이 천천히 움직이고(손가락이 과녁을
  가리지 않게), 손을 떼면 쏜다. 키보드는 방향키로 조준(`Shift` 는 미세 조정), `Space` 를 누르고 있다 떼서 쏜다. `M` 소리.
- 바람은 세트마다 바뀌고 쏘는 동안에도 돌풍이 오르내린다. 오른쪽 위 나침반(위가 과녁 쪽)과 과녁 위 깃발로 보고,
  바람이 불어오는 쪽으로 겨눈다. 옆바람 1 m/s 에 약 4.5cm 밀린다. 컴퓨터의 조준점이 어디로 가는지 보면 참고가 된다.
- 화살 하나에 20초. 넘기면 0점(M).
- `archery/js/target.js`(과녁 규격·점수), `match.js`(세트제 규칙), `tournament.js`(토너먼트·상대), `wind.js`(바람),
  `aim.js`(조준 흔들림), `ai.js`(컴퓨터)는 순수 로직이고 `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.

## 과일 팡팡

- 가로 6 × 세로 12 칸 판 두 개에서 겨루는 대전 퍼즐. 과일 두 개가 붙은 짝을 옮기고 돌려 쌓고, 같은 과일이
  상하좌우로 4개 이상 이어지면 터진다. 위의 과일이 내려와 또 터지면 연쇄다. 두 사람은 같은 순서의 짝을 받는다.
- 터뜨린 점수 70점마다 상대에게 코코넛(방해 블록) 하나를 보낸다. 연쇄가 길수록, 한꺼번에 여러 과일·큰 묶음을
  터뜨릴수록 점수가 크게 뛴다(2연쇄 5개, 3연쇄 14개, 4연쇄 32개쯤). 코코넛은 옆에서 과일이 터질 때만 사라진다.
- 받을 코코넛은 판 위에 표시된다(작은 것 1개, 중간 6개, 큰 것 30개). 상대의 연쇄가 끝난 뒤, 내가 터뜨리지 못한
  차례에 한 번에 30개까지 떨어진다. 그 전에 내가 터뜨리면 그만큼 지우고 남는 것만 상대에게 간다.
  판을 완전히 비우면 다음 공격에 18개가 덧붙는다.
- ✕ 표시된 칸(왼쪽에서 셋째 줄 맨 위)이 막히면 진다. 시간이 갈수록 빨리 떨어지고, 90초 뒤부터는 코코넛 값이
  20초마다 싸져서 승부가 난다.
- 시작 화면에서 상대(컴퓨터 / 친구), 컴퓨터 실력(쉬움·보통·어려움), 과일 종류(3·4·5종)를 고른다.
  컴퓨터 상대 전적과 최고 연쇄는 실력·종류마다 localStorage 에 남는다.
- 조작(혼자): `←`/`→` 옮기기, `↓` 빨리 내리기, `↑`·`X` 시계 방향, `Z` 반시계 방향, `Space` 바로 떨어뜨리기
  (`A`/`D`/`S`/`W`/`Q` 도 된다). 친구와: 1P `A`/`D`, `S`, `W`·`Q`, `Space` · 2P `←`/`→`, `↓`, `↑`·`/`, `Enter`.
  `P` 일시정지, `M` 소리. 터치는 아래 조작판을 쓰고, 2인 대전에서는 판마다 조작판이 하나씩 나온다.
- 세로로 긴 화면에서 혼자 할 때는 내 판을 크게, 상대 판을 작게 그린다. 낮은 가로 화면에서는 조작판이 양옆으로 간다.

  `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.

## 메모리 카드

- 덮인 카드를 두 장씩 뒤집어 같은 동물끼리 짝을 맞춘다. 틀리면 1.1초쯤 보여 준 뒤 다시 덮는다.
  시작 화면에서 인원(혼자서 / 2인 대전)과 카드 수(12·20·30장)를 고른다. 동물은 30종 중에서 매번 새로 뽑는다.
- **혼자서**: 첫 카드를 뒤집을 때부터 시간이 흐르고, 두 장을 뒤집을 때마다 턴이 하나 는다. 가장 빠른 시간과
  가장 적은 턴 수가 카드 수마다 따로 localStorage 에 남고, 둘 중 하나라도 깨면 새 최고 기록이다.
  틀린 카드가 펼쳐져 있을 때 다음 카드를 바로 눌러도 된다(기다리는 시간을 줄일 수 있다).
- **2인 대전**: 한 기기에서 번갈아 한다. 짝을 맞추면 한 번 더, 틀리면 차례가 넘어가고, 짝을 더 많이 모은 사람이 이긴다.
  누구 차례인지는 네 곳에 같이 나온다 — 위쪽 점수판에서 차례인 사람이 자기 색으로 채워지고 `차례` 표가 붙으며,
  그 아래 안내 줄에 이름이 나오고, 화면 가장자리와 펠트 테두리가 그 사람 색(1P 파랑, 2P 노랑)으로 빛난다.
  차례가 바뀔 때는 가운데에 큰 글씨로도 알린다. 맞춘 카드 밑에는 맞춘 사람 색 테가 깔린다.
  틀린 카드가 펼쳐져 있을 때 누르면 카드를 덮고 차례만 넘긴다. 한 판 더 하면 먼저 하는 사람이 바뀐다.
- 조작: 카드를 탭·클릭하거나 방향키로 고르고 `Space`/`Enter` 로 뒤집는다. `R` 새 판, `M` 소리, `Esc` 메뉴.
- 카드를 몇 줄로 놓을지는 화면 비율에 맞춰 정한다(세로 화면이면 세로로 길게). 화면을 돌리면 다시 놓는다.
- `memory/js/game.js`(규칙·배치), `save.js`(기록)는 순수 로직이고 `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.
- 에셋 출처는 [`memory/assets/CREDITS.md`](memory/assets/CREDITS.md) 참고.
