# Casual Games

브라우저에서 바로 즐기는 간단한 게임 모음. 게임마다 디렉토리를 하나씩 쓴다.

| 디렉토리 | 게임 |
| --- | --- |
| [`poker/`](poker/) | 3D 포커 — 컴퓨터와 1:1로 겨루는 텍사스 홀덤, 오마하, 파이브 카드 드로우, 세븐 카드 스터드 |
| [`darts/`](darts/) | 다트 301 — 흔들리는 조준점을 맞춰 던져 컴퓨터보다 먼저 0점 만들기 |
| [`bowling/`](bowling/) | 볼링 — 위치·방향·세기를 맞춰 굴려 핀을 쓰러뜨리는 3D 텐핀 볼링, 컴퓨터와 10프레임 승부 |
| [`blackjack/`](blackjack/) | 3D 블랙잭 — 6덱 슈로 딜러와 1:1, 히트·스탠드·더블·스플릿·인슈어런스 |
| [`defense/`](defense/) | 타워 디펜스 — 길목에 타워를 세워 20웨이브의 적을 막아 기지 지키기 |

## 실행

빌드 과정은 없다. 다만 `index.html` 을 파일로 직접 열면(`file://`) 동작하지 않는다. 브라우저가
`file://` 에서는 ES 모듈 스크립트와 텍스처·모델 로딩을 보안상 막기 때문이다. 정적 서버로 연다.

```sh
npm start        # python3 -m http.server 8000
```

http://localhost:8000 에서 게임을 고른다.

## 테스트

```sh
npm test         # node --test
```

## 새 게임 추가

1. 최상위에 게임 디렉토리를 만들고 `index.html` 을 둔다.
2. 루트 `index.html` 의 `games` 배열에 항목을 추가한다.

## 3D 포커

종목은 시작 화면에서 고르거나 `poker/index.html?game=holdem` 처럼 주소로 지정한다.

| 종목 | `game` | 방식 |
| --- | --- | --- |
| 텍사스 홀덤 | `holdem` | 내 카드 2장 + 공용 카드 5장, 노리밋 |
| 오마하 | `omaha` | 내 카드 4장 중 정확히 2장 + 공용 카드 3장, 팟 리밋 |
| 파이브 카드 드로우 | `draw` | 5장을 받고 한 번 교환, 노리밋 |
| 세븐 카드 스터드 | `stud` | 7장 중 4장 공개, 앤티 방식, 공개 패가 높은 쪽이 먼저 베팅 |

- 시작 칩 1,000, 블라인드 10/20 (스터드는 앤티 10). 한쪽 칩이 모두 떨어지면 게임이 끝난다.
- 단축키: `F` 폴드, `C` 체크/콜, `R` 벳/레이즈, `Enter` 다음 핸드.
  드로우에서는 카드를 클릭하거나 `1`~`5` 로 바꿀 카드를 고르고 `Enter` 로 확정한다.
- 종목별 차이는 `poker/js/variants.js` 에 선언되어 있어, 종목을 추가할 때는 여기에 정의를 더한다.
- `poker/js/game.js`(규칙), `hand.js`(족보), `ai.js`(컴퓨터)는 렌더링과 분리된 순수 로직이고,
  `scene.js`(Three.js 씬)와 `main.js`(HUD·진행)가 이를 화면에 그린다.
- Three.js 는 CDN 에서 불러오므로 인터넷 연결이 필요하다.
- 3D 모델·텍스처·카드 이미지는 모두 CC0/퍼블릭 도메인 오픈소스 에셋이다. 출처는
  [`poker/assets/CREDITS.md`](poker/assets/CREDITS.md) 참고.

## 다트 301

- 301점에서 시작해 한 턴에 다트 3개를 던지고, 남은 점수를 정확히 0 으로 만들면 이긴다.
  남은 점수보다 많이 맞히면 버스트로 그 턴의 점수가 무효가 된다. (더블 아웃 규칙은 없다.)
- 조준점은 포인터 주변에서 계속 흔들린다. 원하는 구역 위에 왔을 때 클릭(터치는 손을 뗄 때)해 던진다.
- `darts/js/board.js`(보드 규격·점수), `game.js`(규칙), `ai.js`(컴퓨터)는 순수 로직이고
  `scene.js`, `main.js` 가 화면을 담당한다.
- `darts/index.html?debug` 로 열면 점수 계산에 쓰는 규격선이 보드 모델 위에 겹쳐 그려진다.
- 에셋 출처는 [`darts/assets/CREDITS.md`](darts/assets/CREDITS.md) 참고.

## 볼링

- 컴퓨터와 번갈아 10프레임을 치는 텐핀 볼링. 스트라이크·스페어·10프레임 보너스 투구까지 표준 점수 규칙을 따른다.
  파울과 스플릿 표시는 없다.
- 투구는 세 단계다. 포인터(또는 `←`/`→`)로 공을 놓을 위치를 고르고, 좌우로 흔들리는 조준선과
  오르내리는 세기 게이지를 차례로 클릭(터치는 탭)하거나 `Space`/`Enter` 로 확정한다.
- 스핀은 `1` 왼쪽 훅, `2` 직구, `3` 오른쪽 훅. `Esc` 로 위치 단계로 돌아간다.
- `bowling/js/game.js`(점수 규칙), `lane.js`(레인 규격·쓰러짐 판정), `ai.js`(컴퓨터)는 순수 로직이고
  `physics.js`(cannon-es 물리), `scene.js`, `main.js` 가 화면을 담당한다.
- Three.js 와 cannon-es 는 CDN 에서 불러온다.
- 에셋 출처는 [`bowling/assets/CREDITS.md`](bowling/assets/CREDITS.md) 참고.

## 3D 블랙잭

- 시작 칩 1,000, 최소 베팅 10. 칩이 10 아래로 떨어지면 게임이 끝난다.
- 6덱 슈를 쓰고 75% 를 쓰면 다음 라운드 전에 다시 섞는다. 블랙잭은 3:2, 딜러는 소프트 17 을 포함한
  모든 17 에서 스탠드, 푸시는 베팅을 돌려받는다.
- 딜러가 A 를 보이면 인슈어런스(베팅의 절반, 2:1 지급)를 고를 수 있다. 더블은 처음 두 장에서,
  스플릿은 같은 랭크일 때 4핸드까지 가능하다. 스플릿한 A 는 한 장씩만 받는다. 서렌더는 없다.
- 단축키: `1`~`4` 칩, `Backspace` 베팅 지우기, `Enter` 딜, `H` 히트, `S` 스탠드, `D` 더블, `P` 스플릿,
  `Y`/`N` 인슈어런스.
- `blackjack/js/rules.js`(핸드 값·정산), `shoe.js`(슈), `game.js`(진행)는 순수 로직이고
  `scene.js`, `main.js` 가 화면을 담당한다.
- 에셋 출처는 [`blackjack/assets/CREDITS.md`](blackjack/assets/CREDITS.md) 참고.

## 타워 디펜스

- 고정 경로로 기지를 향해 오는 적을 타워로 막는다. 20웨이브를 버티면 승리, 목숨(20)이 0 이 되면 패배.
  5·10·15·20 웨이브에는 보스가 나온다.
- 타워는 궁수탑(빠른 단일 공격), 대포(범위 피해), 빙결탑(둔화) 세 종류. 각각 3레벨까지 업그레이드하고,
  팔면 투자액의 70% 를 돌려받는다.
- `1`~`3` 이나 아래 버튼으로 타워를 고르고 칸을 클릭해 짓는다. 터치는 빈 칸을 탭한 뒤 타워 버튼을 누른다.
  타워를 누르면 사거리와 업그레이드/판매 패널이 나온다.
- 단축키: `U` 업그레이드, `X` 판매, `Space` 웨이브 시작/일시정지, `F` 2배속, `M` 소리, `Esc` 취소.
- 진행 상태는 브라우저 localStorage 에 자동 저장되어 다음에 이어서 할 수 있다. 전투 중의 변화는 저장하지
  않으므로, 전투 중에 새로고침하면 그 웨이브 시작 직전 상태로 돌아간다. 최고 기록도 따로 남는다.
- `defense/js/game.js`(시뮬레이션), `map.js`, `towers.js`, `enemies.js`, `waves.js`(데이터), `save.js`(저장)는
  순수 로직이고 `scene.js`, `main.js`, `sound.js` 가 화면과 소리를 담당한다.
- 에셋 출처는 [`defense/assets/CREDITS.md`](defense/assets/CREDITS.md) 참고.
